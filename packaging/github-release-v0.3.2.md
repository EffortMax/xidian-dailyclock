## XDU Course Assistant v0.3.2

本版本重点修复自动选课持续轮询时的日志可见性，并优化桌面界面的空间与日志查看体验。发布包继续沿用 v0.3.1 已验证的精简 Windows x64 单文件构建方案。

### 自动选课日志

- 每次课程列表轮询都会输出带编号的开始日志、待处理目标数、轮次完成状态和下次等待时间。
- 满员、空结果等目标状态细节仍只在发生变化时重复输出，既保留心跳又避免无意义刷屏。
- 网络异常、会话恢复、选课提交结果和最终已选课程复核日志保持不变。
- 自动选课服务日志统一通过 `TaskThread` 信号回到 Qt 主线程，不再由工作线程直接操作日志控件。

### 桌面界面

- 统一页面边距、表单间距和按钮尺寸。
- 目标队列、课程操作和自动任务按钮按用途分组，减少无效拉伸。
- 业务区与运行日志区改为可拖动的纵向分隔布局；日志区默认高度提升，也可一键展开和恢复。
- 日志工具栏新增自动滚动、复制全部、UTF-8 保存、确认清空和日志条数统计。
- UI 日志增加 `[HH:MM:SS]` 时间戳；关闭自动滚动后，查看历史内容时不会被新日志拉回底部。
- 使用 `QSettings` 记忆日志面板尺寸和自动滚动设置。

### 验证与兼容性

- 通过 31 项自动化测试，包括三轮状态不变的轮询心跳、Qt 线程安全日志回调、日志面板尺寸、展开/恢复、设置记忆、自动滚动、复制、保存和清空。
- 受控实时轮询验证确认连续三轮均有完整心跳，未造成课程状态变化。
- 保留可选的 Windows DPAPI 凭据保存、双确认退课、最终状态复核、无人值守 OCR、课表导出和 CLI 兼容性。
- 继续保留 `opengl32sw.dll`，兼顾无 GPU、远程桌面和显卡驱动异常环境。
